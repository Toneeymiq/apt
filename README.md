# apt

Class work.

## Quick setup (Ubuntu/Debian)

Install the common tools used in Applied Computer Science labs:

```bash
sudo apt update
sudo apt install -y build-essential gdb cmake python3 python3-pip
```

## Run examples

This repository includes simple starter programs for C, C++, and Python.

```bash
make run-c
make run-cpp
make run-python
```

## Project structure

- `examples/c/main.c` - C starter
- `examples/cpp/main.cpp` - C++ starter
- `examples/python/main.py` - Python starter
